# Империя Цинь

> Первая централизованная империя: единое письмо, меры, Великая стена и террактовая армия.

| | |
|---|---|
| **Тип** | империя |
| **Период** | 221 до н.э. — 206 до н.э. |
| **Регионы** | Северный Китай, Южный Китай, Индокитай |

## Подробнее

Цинь Шихуанди объединил Поднебесную, упразднил уделы, ввёл округа, единые меры, иероглифику и денежную систему. Жёсткость режима привела к быстрому краху после его смерти.
