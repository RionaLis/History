## 0. Почему не GitHub Pages

Сейчас ваш репозиторий публикуется на Pages. Для публичного демо это
нормально, но для закрытого просмотра не годится **в принципе**, и это не
настройка, которую можно подкрутить:

GitHub Pages отдаёт **любой** загруженный файл **любому** человеку без пароля.
Единственная «защита» — что адрес трудно угадать. Достаточно одного человека,
который откроет исходный код страницы, найдёт путь к тайлу — и у него прямая
ссылка, которую можно передать кому угодно или встроить в чужой сайт.

Отсюда правило: **никогда не кладите на Pages то, что нельзя показывать всем.**
Включая `gaps.md` — это по сути список того, что у вас ещё не сделано.

Ключ `--check` не косметический: он обходит всё дерево `public/` и ищет имена,
которым там не место — `.csv`, `.yml`, `.py`, `.md`, `gaps`, `geom`, `_cache`,

конспект, и следующий запуск скопирует его в интернет. Проверка скажет об этом
вслух.

Проверено отдельно: все девять путей к исходникам дают 404 —
`maps/eras/rome117/qgis/gaps.md`, `polities.csv`, `sea_battles.csv`,
`era.yml`, `tools/make_public.py`, `deploy/worker.js`,
`maps/_cache/overpass/areas_117.json`, `maps/eras/rome117/geom/all.geojson`,
`out/era-rome117.geojson`.

### Две подмены, которые делает make_public.py

**1. Библиотека MapLibre по умолчанию копируется В `public/`, а не берётся
с CDN.** Это сделано именно из-за доступности из России: зависимость от
зарубежного CDN, отдающего обязательный файл, — точка отказа. Теперь страница
**не делает внешних запросов вообще**; единственные внешние ссылки — исходящие,
на ваши статьи и на Wikidata при клике на объект. Проверено: в отданном
`index.html` нет ни одного `https://` на ресурсы страницы.

Флаг `--cdn` переносит библиотеку на jsdelivr и нужен ровно для одного случая:
публикации через Cloudflare Worker, где весь код ограничен 1 МБ, а
`maplibre-gl.js` весит 1 056 837 байт — ровно весь лимит. Для России этот
сценарий нерабочий.

Что подменяется при `--cdn`:

```html
<!-- было -->
<link rel="stylesheet" href="maplibre-gl.css">
<script src="maplibre-gl.js"></script>

<!-- стало -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/maplibre-gl@5.24.0/dist/maplibre-gl.css">
<script src="https://cdn.jsdelivr.net/npm/maplibre-gl@5.24.0/dist/maplibre-gl.js"></script>
```

Проверено: jsdelivr отдаёт файл размером **1 056 837 байт** — байт в байт как
ваш локальный, версия 5.24.0 совпадает. Плата — зависимость от CDN: если
jsdelivr недоступен, карта не откроется. На платном тарифе Worker'а лимит кода
10 МБ, и библиотеку можно вернуть к себе (см. шаг 08, §3).

**2. Ключ доступа читается из якоря адреса.** Якорь — всё после `#`. Браузер
**не отправляет** его на сервер, поэтому ключ:

* не попадает в журналы Cloudflare, R2 и вашего провайдера;
* не светится в истории посещений как часть запроса;
* не уходит в заголовок Referer на сторонние сайты.

Если бы ключ был в `?k=…`, он осел бы в логах навсегда. Дополнительно
вставляется `<meta name="referrer" content="no-referrer">`: без него ключ всё
равно утёк бы на CDN и Wikidata через Referer, потому что перехватчик `fetch`
добавляет `?k=…` к запросам тайлов.

## 2. ВАРИАНТ 1. Туннель — СПРАВКА, из России не работает

> `trycloudflare.com` — это сеть Cloudflare, значит на неё действует то же
> обрезание после 16 КБ. Раздел оставлен на случай зарубежной площадки.

**Когда выбирать:** показать прямо сейчас, друзьям на пару дней, проверить
карту на телефоне.

**Ограничение:** работает, только пока ваш компьютер включён и открыт терминал.

### Шаг 1. Установить cloudflared

```bash
curl -L --output cloudflared.deb \
  https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
sudo dpkg -i cloudflared.deb
rm cloudflared.deb
cloudflared --version
```

Если `dpkg` ругается на зависимости:

```bash
sudo apt --fix-broken install
```

### Шаг 2. Поднять сервер

```bash
cd ~/history-demo
python3 tools/make_public.py --serve
```

Терминал теперь занят — не закрывайте его. Для следующего шага откройте второй.

Скрипт печатает свой корень, **проверьте эту строку**:

```
  корень:  /home/user/history-demo/public
  адрес:   http://localhost:8080/
```

> **Это не формальность.** Однажды сервер поднялся с корнем проекта вместо
> `public/` и исправно отдавал `maps/eras/*/qgis/gaps.md`, `polities.csv`,
> `era.yml` и кэш Overpass кодом 200 — то есть всё, что публиковать нельзя.
> Причина была в том, что `devserver.py` брал корень от своего расположения и
> игнорировал аргументы. Заметить удалось только по размеру `index.html`:
> 1004 байта вместо 19300. Теперь есть ключ `--root` и предупреждение при
> запуске.

Запустить вручную:

```bash
python3 tools/devserver.py 8080 --root public
```

Убедиться, что исходники закрыты — все четыре должны дать **404**:

```bash
for f in maps/ tools/ out/ maps/_cache/; do
  printf "  %-16s " "$f"
  curl -s -o /dev/null -w "%{http_code}\n" "http://localhost:8080/$f"
done
```

> Сервер здесь — `tools/devserver.py`, а не `python3 -m http.server`. Разница
> принципиальна: обычный http.server отвечает на Range-запросы кодом 200 и
> отдаёт файл целиком, а PMTiles читает тайл кусками и требует **206 Partial
> Content**. С `http.server` карта просто не откроется. Ещё он не отвечает на
> OPTIONS-префлайт, нужный для CORS.

### Шаг 3. Пробросить туннель

### Шаг 4. Дать ссылку

```
https://random-words-three-1234.trycloudflare.com/#k=СЕКРЕТ
```

Ключ задаёте вы сами, любая длинная случайная строка:


> временный, никому не известен и исчезает, когда вы закрываете терминал.
> Если нужно закрыть тайлы ключом по-настоящему — это вариант 2.

### Шаг 5. Остановить

`Ctrl+C` в обоих терминалах. Адрес перестаёт работать сразу.

## 3. ВАРИАНТ 2. R2 + Worker — СПРАВКА, из России не работает

> `*.workers.dev` заблокирован РКН, а трафик к сетям Cloudflare обрезается
> после 16 КБ. Карты российских банков при оплате отклоняются. Раздел оставлен
> как справка и на случай переезда.

**Когда выбирать:** ссылка должна работать всегда, независимо от вашего
компьютера, и тайлы должны быть закрыты по-настоящему.

**Как работает.** Тайлы лежат в хранилище Cloudflare R2. Раздаёт их маленький
Worker (`deploy/worker.js`), который проверяет ключ в каждом запросе. Нет
ключа — **403**, и содержимое файла не отдаётся.

**Бесплатные лимиты** (сверено с developers.cloudflare.com в октябре 2026):

| | Бесплатно | Ваш расход |
|---|---|---|
| R2 хранилище | 10 ГБ | **3 МБ** |
| R2 исходящий трафик | **без ограничений** | — |
| R2 чтение (класс B) | 10 млн/мес | сотни тысяч |
| Workers запросы | 100 000/сутки | ~300 на просмотр |
| Workers код | 1 МБ | **11 КБ** |

**Почему именно R2.** У всех остальных бесплатных хостингов исходящий трафик
ограничен, и карта, которую смотрят несколько человек, этот лимит съедает
быстро. У R2 исходящий трафик бесплатен и не ограничен — единственное такое
предложение среди крупных облаков.

**Свой домен не нужен.** Worker получает бесплатный адрес
`https://chrono-mapa.<ваш-аккаунт>.workers.dev`.

Я проверил это отдельно, потому что раньше поддомены `workers.dev`
блокировали запросы с заголовком `Origin`, и браузерная карта с другого адреса
не работала. Замер от 22.10.2026: чужой Worker на
`welcome.developers.workers.dev` отвечает на запрос с
`Origin: https://rionalis.github.io` кодом **200**, а не 403. Значит
блокировки нет. На OPTIONS он ответил 405 — но только потому, что сам OPTIONS
не обрабатывает; наш Worker обрабатывает и отвечает 204.

### Шаг 7. Проверить, что ключ действительно защищает

Пять проверок, делать руками, а не на слово:

```bash
АДРЕС="https://chrono-mapa.<ваш-аккаунт>.workers.dev"
КЛЮЧ="ваш-ключ-из-шага-5"

# 1. без ключа — должно быть 403
curl -s -o /dev/null -w "index без ключа:   %{http_code}\n" "$АДРЕС/"

# 2. с ключом — должно быть 200
curl -s -o /dev/null -w "index с ключом:    %{http_code}\n" "$АДРЕС/?k=$КЛЮЧ"

# 3. тайл без ключа — должно быть 403
curl -s -o /dev/null -w "тайл без ключа:    %{http_code}\n" \
  "$АДРЕС/tiles/era-rome117.pmtiles"

# 4. тайл с ключом и Range — должно быть 206, а не 200
curl -s -o /dev/null -w "тайл с Range:      %{http_code}\n" \
  -H "Range: bytes=0-1023" "$АДРЕС/tiles/era-rome117.pmtiles?k=$КЛЮЧ"

# 5. CORS-префлайт — должно быть 204
curl -s -o /dev/null -w "OPTIONS:           %{http_code}\n" -X OPTIONS \
  -H "Origin: https://example.com" "$АДРЕС/tiles/era-rome117.pmtiles"
```

Ожидаемый результат: **403, 200, 403, 206, 204**.

Если четвёртая строка даёт 200 вместо 206 — карта будет открываться медленно
или не откроется вовсе: Range не прошёл. Смотреть, что ответил Worker:

```bash
npx wrangler tail
```

и в другом терминале повторить запрос.

## 5. Чего эта защита НЕ делает, честно

Ключ в URL — защита от случайного человека и от поисковиков, а не от того, кто
захочет данные забрать. Любой, кто откроет инструменты разработчика, увидит
запросы к тайлам вместе с ключом и сможет скачать все три файла скриптом.

Для этапа «вы и пара друзей» этого достаточно, и это ровно то, что бесплатно.
Когда проект станет платным, нужно другое: короткоживущие подписанные токены,
которые Worker выдаёт после проверки подписки. Схема — в шаге 08, §6.1.

Отдельно: **лицензии**. То, что вы публикуете даже закрыто, всё равно требует
соблюдения лицензий источников. Natural Earth (Public Domain), OHM (CC0) и
Wikidata (CC0) — без ограничений. **Pleiades — CC BY 3.0, атрибуция
обязательна**: если в слое есть данные Pleiades, на странице должна быть
ссылка на источник.

## 6. Если что-то не работает

| Симптом | Причина | Что делать |
|---|---|---|
| **Страница грузится и обрывается на ~16 КБ** | **Cloudflare из России** | Уйти с Cloudflare на российский VPS, см. §0 |
| Библиотека не загружается | Собрали с `--cdn`, а CDN недоступен | Пересобрать без флага: `make_public.py --check` |
| Телефон не видит локальный сервер | Файрвол или изоляция клиентов роутера | `sudo ufw allow 8080/tcp`; выключить AP isolation |
| Карта не открывается, в консоли `403` | Ссылка дана без `#k=…` | Отправить адрес целиком; проверить, что мессенджер не обрезал хвост |
| `Failed to fetch` / CORS-ошибка | Worker не ответил на OPTIONS | Пятая команда шага 7: должно быть 204 |
| Карта белая, в консоли про `206` | Сервер отвечает 200 на Range | Использовать `tools/devserver.py`, а не `python3 -m http.server` |
| Отдаются исходники | Сервер поднят не из `public/` | Смотреть напечатанный при запуске корень; `--root public` |
| Тайлы скачиваются, но не рисуются | Файл недозалит | `npx wrangler r2 object get` и сравнить размер с локальным |
| После обновления видна старая карта | Кэш браузера на сутки | Ctrl+Shift+R |
| `wrangler deploy` ругается на размер | В Worker положили библиотеку | `maplibre-gl.js` должен идти с CDN, не из R2 |
| Туннель не поднимается | Порт занят | Другой порт и `--url http://localhost:ДРУГОЙ` |
| Worker печатает «Ключ доступа не задан» | Секрет не положен | `npx wrangler secret put ACCESS_KEY` |

Убрать всё:

```bash
cd ~/history-demo/deploy
npx wrangler delete
npx wrangler r2 bucket delete chrono-tiles
```
