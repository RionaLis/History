# ШАГ 02. Подложка: реки, озёра и современные границы

Подложка делается **один раз** и используется всеми эпохами. Это то, что
видно на карте всегда, независимо от выбранного года: очертания материков,
крупные реки, озёра и современные границы — чтобы посетитель понимал, где
находится.

Занимает 5 минут.

---

## 1. Откуда берём и почему именно оттуда

Источник — **Natural Earth**. Лицензия Public Domain: можно использовать в
платном продукте без ограничений и без атрибуции.

> **★ Грабля.** Официальная страница загрузок `naturalearthdata.com/downloads/`
> возвращает **406 Not Acceptable** на запросы из командной строки — там стоит
> защита от ботов. Рабочий зеркальный хост — **`naciscdn.org`**. Проверено.

---

## 2. Скачиваем

```bash
cd ~/history-demo
mkdir -p ne && cd ne

# Реки, масштаб 1:50 млн — основной рабочий слой
curl -L -o rivers50.zip \
  https://www.naciscdn.org/naturalearth/50m/physical/ne_50m_rivers_lake_centerlines.zip

# Озёра, масштаб 1:50 млн
curl -L -o lakes50.zip \
  https://www.naciscdn.org/naturalearth/50m/physical/ne_50m_lakes.zip

# Реки, масштаб 1:110 млн — для самых дальних зумов
curl -L -o rivers110.zip \
  https://www.naciscdn.org/naturalearth/110m/physical/ne_110m_rivers_lake_centerlines.zip

# Современные границы государств, 1:110 млн
curl -L -o admin110.zip \
  https://www.naciscdn.org/naturalearth/110m/cultural/ne_110m_admin_0_countries.zip

unzip -o '*.zip'
ls *.shp
```

Должны появиться четыре файла `.shp` вместе с `.dbf`, `.shx`, `.prj`, `.cpg`:

```
ne_110m_admin_0_countries.shp
ne_110m_lakes.shp
ne_110m_rivers_lake_centerlines.shp
ne_50m_lakes.shp
ne_50m_rivers_lake_centerlines.shp
```

> **Нужны именно `.shp`, а не `.geojson`.** Natural Earth распространяет
> shapefile, и `prep_base.py` читает его через `pyshp`. GeoJSON-версии на
> сайте есть не для всех слоёв.

## 3. Какой масштаб рек зачем

| Файл | Объектов | Для чего |
|---|---:|---|
| `rivers-110m` | 13 | Зумы 0–3. Только крупнейшие: Нил, Амазонка, Миссисипи, Янцзы, Обь, Енисей, Лена, Амур, Хуанхэ, Конго, Маккензи, Нигер, Волга |
| `rivers-50m` | **477** | Зумы 4–7. Основной рабочий слой |
| `lakes-50m` | 412 | Зумы 4–7 |
| `lakes-110m` | 24 | Зумы 0–3 |
| `modern-borders` | 177 | Современные границы, зумы 0–5 |

> **Для Тигра, Евфрата, Нила, Инда, Ганга, Дуная, Рейна и Тибра нужен именно
> 50m.** В 110m их просто нет — там 13 рек на весь мир. Если возьмёте 110m для
> карты Древнего Востока, на ней не окажется ни одной реки, вокруг которых
> всё и происходило.

## 5. Три вещи, которые стоит знать про результат

### 5.1. Natural Earth уже несёт Q-номера Wikidata

Замерено: **550 из 600** объектов гидрографии подложки (92%) имеют заполненное
поле `wikidata`. Примеры из реального файла:

```
Q79082    Кама          name_local=Kama
Q34589    Евфрат        name_local=Euphrates
Q1241991  Олбани        name_local=Albany
Q1653     Дунай         name_local=Danube
```

Это основа шага 05: сопоставление исторических названий идёт **по Q-номеру**,
а не по названию, и поэтому работает надёжно.

> **Но там попадается мусор.** Замерено: у озера Неято и озера Ямбуто в поле
> `wikidata` стоит `-1`. Это не Q-номер. `harvest_wikidata.py` проверяет каждый
> номер регулярным выражением `^Q[1-9]\d*$` и отбрасывает такие, сообщая вслух.

### 5.2. Морей в Natural Earth НЕТ

Замерено на срезе 117 года: в слое гидрографии 645 объектов
(319 LineString, 182 MultiLineString, 143 Polygon, 1 MultiPolygon) — и
**ни одного моря**. Не нашлось Чёрного, Средиземного, Мраморного, Эгейского,
Азовского, Каспийского, Балтийского, Красного. В `lakes-50m.geojson` из 412
объектов слово «Black» встречается один раз, «Mediterranean» — ноль,
«Caspian» и «Baltic» — ноль.

Это не ошибка, а устройство источника: Natural Earth — данные **суши**. Море
там получается пустым местом между береговыми линиями, отдельного полигона
«Чёрное море» в них нет и не будет.

Поэтому подписи морей создаёт `match_waters.py` из координат Wikidata —
см. шаг 05.

### 5.3. `places-historical.geojson` сжимает Pleiades в 16 раз

Исходный дамп Pleiades весит 4 732 КБ. В слой подложки попадает 290 КБ —
в 16,3 раза меньше, потому что берутся только нужные поля и только объекты,
относящиеся к древности.

> **Pleiades — CC BY 3.0, атрибуция ОБЯЗАТЕЛЬНА.** Если используете этот
> слой, на сайте должна быть ссылка на источник. Это единственное ограничение
> среди всех источников подложки: Natural Earth — Public Domain, OHM — CC0,
> Wikidata — CC0.

## 6. Проверка

```bash
python3 -c "
import json, os
for fn in sorted(os.listdir('maps/base')):
    d = json.load(open('maps/base/' + fn))
    n = len(d.get('features', []))
    wd = sum(1 for f in d['features'] if (f.get('properties') or {}).get('wikidata'))
    print(f'  {fn:28s} {n:5d} объектов   с wikidata: {wd}')
"
```

Все шесть файлов должны читаться без ошибок.
