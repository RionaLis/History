# ПУТЕВОДИТЕЛЬ: карта мира по эпохам без зависимости от OpenHistoricalMap

Это входная точка. Здесь — порядок действий и что где искать. Подробные
команды каждого шага лежат в отдельных файлах папки `инструкции/`.

---

## Как устроен конвейер

Эпоха проходит семь шагов. Каждый шаг — отдельная инструкция, и каждый
можно перезапускать независимо: провал на шаге 5 не портит результат шага 3.

```
  0  УСТАНОВКА          → 01_установка.md
     Python, Java 21, osmium, пакеты. Один раз на машину.

  1  ПОДЛОЖКА           → 02_подложка.md
     Natural Earth → maps/base/  (современные реки, озёра, границы)
     Один раз, дальше переиспользуется всеми эпохами.

  2  ПАСПОРТ ЭПОХИ      → 03_срез_эпохи.md
     maps/eras/<эпоха>/era.yml — год, окно, что должно быть на карте

  3  СРЕЗ ДАННЫХ        → 03_срез_эпохи.md
     extract_era.py → границы, культуры, города, пути, реки эпохи
     Результат: geom/*.geojson + qgis/ + *.auto.csv + gaps.md

  4  СОБОР ИЗ WIKIDATA  → 04_слои_wikidata.md
     harvest_wikidata.py → морские сражения, эпидемии, названия водоёмов
     То, чего в OpenHistoricalMap нет вовсе.

  5  СОПОСТАВЛЕНИЕ      → 05_доработка_qgis.md
     match_waters.py → привязать исторические названия к объектам карты
     Пометить всё сомнительное вам на проверку.

  6  ПРОВЕРКА В QGIS    → 05_доработка_qgis.md
     Открыть слои, прочитать отчёты, дорисовать недостающее руками

  7  СБОРКА И ТАЙЛЫ     → 06_сборка_и_тайлы.md
     validate_map.py → build_map.py → make_tiles.py → .pmtiles

  8  ПУБЛИКАЦИЯ         → 07_публикация_бесплатно.md
     make_public.py → public/ → локальная сеть

  9  РОССИЯ: ХОСТИНГ,   → 08_РОССИЯ_хостинг_закон_платежи.md  ★ ГЛАВНЫЙ
     ЗАКОН И ПЛАТЕЖИ       VPS + nginx, домен .ru, 152-ФЗ, самозанятость

 10  СПРАВКА (не для РФ) → 08_переход_на_платное.md
     Cloudflare, Vercel, Hetzner, Stripe — на случай зарубежной площадки
```

## Короткий путь: эпоха за один присест

Когда всё установлено, новая эпоха делается так:

```bash
cd ~/history-demo

# 1. паспорт эпохи
cp -r maps/eras/_template maps/eras/moya_epoha
nano maps/eras/moya_epoha/era.yml        # год, окно, expected

# 2. срез данных из OHM
python3 tools/extract_era.py ohm moya_epoha --overpass

# 3. заготовки CSV → рабочие файлы
for f in polities cultures places routes; do
  cp maps/eras/moya_epoha/$f.auto.csv maps/eras/moya_epoha/$f.csv
done

# 4. слои из Wikidata
python3 tools/harvest_wikidata.py battles   moya_epoha
python3 tools/harvest_wikidata.py epidemics moya_epoha
python3 tools/harvest_wikidata.py waters    moya_epoha
cp maps/eras/moya_epoha/sea_battles.auto.csv maps/eras/moya_epoha/sea_battles.csv
cp maps/eras/moya_epoha/water_names.auto.csv maps/eras/moya_epoha/water_names.csv

# 5. сопоставить названия водоёмов с картой
python3 tools/match_waters.py moya_epoha

# 6. проверить и собрать
python3 tools/validate_map.py moya_epoha
python3 tools/build_map.py era moya_epoha
python3 tools/make_tiles.py

# 7. опубликовать
python3 tools/make_public.py --check
```

Шаг 6 — просмотр в QGIS — между пятым и шестым пунктом. Пропускать его
не стоит: именно там видно, чего в данных не хватает.

```bash

cp ХРОНИСТА_ПАКЕТ/tools/*        ~/history-demo/tools/
cp ХРОНИСТА_ПАКЕТ/deploy/*       ~/history-demo/deploy/

cp ХРОНИСТА_ПАКЕТ/шаблоны/era.yml ~/history-demo/maps/eras/_template/era.yml
chmod +x ~/history-demo/tools/*.py
```

## Три принципа, на которых всё построено

**1. Ничего не берётся из интернета во время показа карты.** Все данные
заранее нарезаны в `.pmtiles` и лежат рядом со страницей. Посетитель не
ждёт ответа чужого сервера и не зависит от его доступности. Это и есть
ответ на ваше требование «без тормозов и зависаний».

**2. Автоматика собирает, человек решает.** Инструменты добывают всё, что
добывается, и **помечают** каждое сомнительное место: тип объекта, дату,
сопоставление названия. Пометка попадает в поле `gap` объекта, в отчёт
`qgis/gaps.md` и в атрибуты слоя, которые видны в QGIS. Ничего не решается
за вас молча.

**3. Если автоматика не уверена — поле остаётся пустым.** Пример из реальной
отладки: первая версия подставляла историческое название водоёма «похожим
на античное» и выдавала Евфрат как «Eufrates» (испанский), Янцзы как
«Karayan Yangtze» (тагальский), Иордан как «Abhainn na hIordáine»
(ирландский). Всё это настоящие названия из Wikidata и всё бесполезно на
карте римской эпохи. Неверное имя на карте хуже пустого: пустое вы заметите,
а «Eufrates» уедет в платный продукт. Поэтому теперь поле пустое, а рядом
лежит список кандидатов.

| Культуры и народы | 12 | 3 |
| Города и памятники | 196 | 1527 |
| Пути | 0 | 5 |
| Морские сражения | — | 9 |
| Реки и озёра эпохи (OHM) | 8 | 45 |
| Подписи акваторий | — | 364 |
| Гидрография всего | 608 | 1009 |

| Слоёв в тайле | 4 | 6 |
| Не найдено из ожидаемого | 6 из 20 | 10 из 44 |

Слои в тайле 117 года: `borders`, `cultures`, `hydro`, `places`, `routes`,
`battles`. Проверено чтением тайла: все шесть объявлены в метаданных и
присутствуют в данных.

Исторические названия водоёмов: **15 из 15** заданных вручную легли на карту,
в том числе Понт Эвксинский, Пропонтида, Геллеспонт, Меотида, Mare Nostrum,
Геркулесовы столбы, Боспор Фракийский, Борисфен, Танаис, Тирас, Данубий.
Из 985 водоёмов Wikidata **912 сопоставлены точно** по Q-номеру, 11 вероятно,
66 не найдено, 1 расхождение Q-номеров помечено.

|---|---|---|
| OpenHistoricalMap (данные) | CC0 | **да, без ограничений** |
| Wikidata | CC0 | **да, без ограничений** |
| Natural Earth | Public Domain | **да, без ограничений** |
| Perry-Castañeda Library Map Collection | Public Domain | да |
| Pleiades | CC BY 3.0 | да, **атрибуция обязательна** |
| Wikipedia (тексты) | CC BY-SA | только переписав своими словами |
| Chronas | CC BY-SA | рискованно |
| David Rumsey Map Collection | CC BY-NC-SA | **нельзя** (NC = некоммерческое) |

| CShapes 2.0 | CC BY-NC-SA | **нельзя** |
