ХРОНИСТА — как загрузить обновление в репозиторий History
==========================================================

Вариант 1. Через Git (рекомендуется)
------------------------------------
1) Скопируйте содержимое этой папки поверх вашего клона (папка History):

   # Windows (PowerShell), из папки, куда распакован архив:
   Copy-Item -Recurse -Force .\hronista-integration\* C:\путь\к\History\

   # macOS / Linux:
   cp -r hronista-integration/. /путь/к/History/

2) В папке History:

   git status                      # посмотреть, что изменилось
   git add -A
   git commit -m "Редизайн «Хрониста»: лендинг, тема, шапка, эпохи, внутренние страницы"
   git push

3) GitHub Pages обновится автоматически (workflow уже настроен, обычно 1–2 минуты).

Проверка перед пушем (локальный сервер, не открывать как file://):

   python3 -m http.server 8080
   # http://localhost:8080/           — лендинг
   # http://localhost:8080/map.html   — карта, лента, таблица


Вариант 2. Через сайт GitHub (без установленного Git)
-----------------------------------------------------
В архиве hronista-changed-files.zip лежат только изменённые и новые файлы.
1) Откройте репозиторий → Add file → Upload files.
2) Перетащите файлы из архива, сохранив структуру папок
   (index.html, map.html, pages/, assets/, content/articles/about.md, README*.md).
3) Commit changes → сайт пересоберётся сам.

ВАЖНО: файлы, которые уже есть в репозитории, при загрузке будут заменены —
это нормально и нужно. Данные (content/, data/, assets/map/) не менялись,
их можно не загружать.


Что изменилось
--------------
• index.html  — новая главная-лендинг: hero-баннер, 11 эпох с пиктограммами,
                превью интерактивной карты, события, карточки, футер со сносками.
• map.html    — приложение (карта · лента · шкала · таблица), бывший index.html.
• pages/      — регионы, события, статьи, о проекте — в новой теме.
• assets/css/theme.css, fonts.css, assets/fonts/ — оформление и шрифты.
• assets/js/landing.js, landing-data.js, pages.js — лендинг и общий топбар.
• assets/img/ — hero-коллаж, превью карты, статуя для цитаты.
• content/articles/about.md — абзац про «Хронисту».
• README.md, README-DESIGN.md, ИЗМЕНЕНИЯ.md — документация.

Подробности по оформлению — README-DESIGN.md, список правок — ИЗМЕНЕНИЯ.md.
