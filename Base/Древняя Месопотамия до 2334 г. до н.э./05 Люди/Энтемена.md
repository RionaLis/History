# Энтемена

## Краткая биография

Энтемена — племянник [[per-eannatum]], продолжатель его политики. Воевал с Уммой при правителе Ур-Лумме и Иле, подтвердил границу по каналу и восстановил старый порядок. Строил храмы Нингирсу и Бабы; оставил знаменитую «серебряную вазу» с изображением орла с львиными головами (символ Нингирсу), подаренную Ниппуру.

Его тексты — основной источник по истории пограничного конфликта ([[doc-lagash-umma-texts]]).

## Периоды правления

Около 2400–2375 гг. до н.э.; даты условны.
