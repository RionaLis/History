# Мескаламдуг

## Краткая биография

Мескаламдуг — правитель Ура, отец [[per-mesanepada]]. Любопытно, что [[doc-sumerian-king-list]] его не упоминает: он известен только по вещам из гробницы PG 755 в Уре (золотой шлем-диадема, печати) и по бусам с его именем из Мари.

Его гробница — одна из богатейших в [[wrk-royal-cemetery-ur]], хотя и не «царская» в строгом смысле.

## Периоды правления

Около 2600 г. до н.э.; дата приблизительная, держится на стратиграфии и родственных связях.
