# Эн-Мебарагеси

## Краткая биография

Эн-Мебарагеси (Энмебарагеси) — правитель Киша, древнейший месопотамский царь, существование которого подтверждено археологически: фрагмент алебастровой вазы из Ниппура с его именем. По [[doc-sumerian-king-list]] он «пленил оружие Элама» и был отцом Агги, противника Гильгамеша.

Его имя значит примерно «господин, (покоривший?) страну Элам»; в традиции он — предпоследний правитель I династии Киша.

## Периоды правления

Около 2700–2600 гг. до н.э. (условно, РД I–II). Список даёт 900 лет — явно легендарная цифра. Точной даты нет: используется приблизительный диапазон.

## Связанные события и источники

- Ваза из Ниппура с именем — древнейшая царская надпись Месопотамии.
