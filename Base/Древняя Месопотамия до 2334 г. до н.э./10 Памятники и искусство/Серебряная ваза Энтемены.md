# Серебряная ваза Энтемены

## Описание

Серебряная ваза с медной ножкой, посвящённая правителем Лагаша Энтеменой богу Нингирсу и подаренная храму Энлиля в [[plc-nippur]]. На тулове — рельеф: львиноголовый орёл Анзуд, держащий двух львов, и олени; по краю — надпись с именем и титулами.

Памятник показывает, как правители использовали дорогие сосуды для укрепления своего авторитета в общешумерском культовом центре.

## Создание

Около 2400–2375 гг. до н.э.; найдена в Телло (древнее Гирсу).

## Что изображено и как устроено

- Серебряное тулово, выколоченное из листа; гравированный рельеф.
- Символ Нингирсу — львиноголовый орёл Анзуд; звери по сторонам.

## Значение

Редкий сохранившийся предмет из драгоценного металла РД III: обычно такие вещи переплавлялись. См. [[con-sumerian-pantheon]], [[plc-nippur]].
