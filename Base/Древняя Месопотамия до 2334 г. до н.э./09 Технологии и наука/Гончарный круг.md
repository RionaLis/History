# Гончарный круг

## Описание

Керамика урукского времени — первая в истории по-настоящему массовая промышленная продукция: стандартные формы, сделанные на быстром круге, в том числе знаменитые «чаши с косым краем» (beveled-rim bowls), служившие мерой для выдачи пайка.

Стандартизация посуды — прямое следствие централизованного распределения: одинаковые меры нужны, чтобы кормить тысячи людей.

## Как это работает

- Круг с осью, вращаемый ногой или рукой помощника; центробежная сила позволяет вытягивать стенки.
- Формы стандартизируются; производительность вырастает на порядок по сравнению с лепкой.

## Исторический путь

- Убейд — первые признаки вращающейся подставки.
- Урук — быстрый круг и массовое производство.
- РД — специализированные мастерские; керамика становится проще и стандартнее ([[cul-early-dynastic]]).

## Значение

Массовая посуда — материальное свидетельство существования института пайков, то есть государственной экономики ([[con-temple-economy]]).
