# Хрониста — оформление сайта

Документ описывает интеграцию нового оформления в проект «Хронолента мира».
Функционал не менялся: карта MapLibre, лента событий, шкала управления,
синхронологическая таблица и внутренние страницы работают как раньше —
изменились разметка страниц, стили и брендинг.

## Бренд

| | |
|---|---|
| Название | **Хрониста** |
| Подпись | События. Искусство. Люди |
| Палитра | пергамент `#FAF5EE` · терракота `#BF5A32` · тёмно-зелёный `#1E3A35` · тёмный текст `#2B2622` |
| Шрифты | Cormorant Garamond (заголовки) + Inter (текст), локальные копии в `assets/fonts/` |
| Логотип | инлайн-SVG «портик» в шапке, без внешних файлов |

## Структура страниц

```
index.html          ЛЕНДИНГ: hero-баннер, эпохи, превью карты, события, карточки, футер
map.html            ПРИЛОЖЕНИЕ (бывший index.html): карта · лента · шкала · таблица
pages/regions.html  Регионы мира            (новое оформление, тот же функционал)
pages/events.html   Ключевые события        (новое оформление, тот же функционал)
pages/entity.html   Статьи и списки объектов (новое оформление, тот же функционал)
pages/about.html    О проекте               (новое оформление, тот же функционал)
```

Куда ведут ссылки:

* «Главная» → `index.html`
* «Карта» → `map.html`
* «Таблица» → `map.html#table` (якорь на зону таблицы)
* карточки сущностей/событий → `pages/entity.html?kind=…&id=…`
* «Показать на таблице» → `map.html#e/<id>` (старые ссылки вида `index.html#e/<id>`
  по-прежнему работают — `index.html` просто лендинг, поэтому хэш обрабатывает `map.html`)

Если важно сохранить старые адреса вида `index.html#v/w_ev_cities`, поменяйте
местами имена файлов (`index.html` ↔ `map.html`) — вся логика уже готова,
приложению достаточно, чтобы его HTML лежал по адресу с `#…` в ссылке.

## Что добавлено в репозиторий

```
assets/css/fonts.css      @font-face для локальных шрифтов
assets/fonts/*.woff2      копии Cormorant Garamond и Inter (кириллица + латиница)
assets/css/theme.css      ВСЁ оформление: палитра, шапка, лендинг, внутренние страницы
assets/js/landing.js      эпохи, счётчики, события и поиск на лендинге из data/index.json
assets/js/landing-data.js офлайн-снимок данных (эпохи, 12 свежих событий, счётчики)
assets/img/hero-stage.*   hero-коллаж (webp + jpg-фолбэк)
assets/img/map-preview.*  превью интерактивной карты для лендинга
assets/img/quote-statue.* статуя для блока с цитатой
```

`assets/css/theme.css` подключается **после** `main.css` и `map.css` и только
переопределяет оформление, поэтому файлы таблицы и карты (`chart.js`,
`map-app.js`, `feed.js`) не тронуты.

## Полоса эпох на главной

На лендинге — 11 эпох с линейными пиктограммами (тот же стиль, что и остальные
иконки сайта). Порядок, названия и пиктограммы заданы в `assets/js/landing.js`:

| Эпоха | Пиктограмма | Данные |
|---|---|---|
| Неолит | колос | `neo` из `data/index.json` |
| Ранние цивилизации | зиккурат | `early_civ` |
| Бронзовый век | бронзовый клинок | `bronze` |
| Железный век | наковальня | `iron` |
| Античность | античный храм | `axial` («Осевое время и классика») |
| Раннее Средневековье | крепость | `early_med` |
| Высокое и позднее Средневековье | готический собор | `high_med` |
| Возрождение | циркуль | витринная запись, ведёт на `map.html?y=1500` |
| Новое время | каравелла | `early_mod` |
| Индустриальная эпоха | завод с трубой | `modern` |
| Новейшее время | ракета | `contemp` |

Даты берутся из индекса, поэтому при правке эпохи в `content/eras/*.md`
и пересборке (`python3 tools/build.py`) подпись на главной обновится сама.

Как поменять:

* состав и порядок — массив `ERA_STRIP` в `assets/js/landing.js`;
* пиктограмму — объект `ERA_ICONS` (ключ = id эпохи), SVG 32×32,
  `stroke="currentColor"`, без заливок;
* ссылку — для реальной эпохи это `map.html#a/<id>` (открывает статью эпохи
  на карте), для витринной — `map.html?y=<год>`.

Клик по эпохе открывает приложение с выбранной эпохой: карта, лента и таблица
синхронизируются, справа открывается статья эпохи.

## Офлайн-снимок данных

Если `data/index.json` недоступен (предпросмотр без сети, открытие по `file://`),
лендинг показывает данные из `assets/js/landing-data.js`. Снимок обновляется
вручную или скриптом; он содержит только эпохи, 12 последних событий и счётчики,
поэтому карта, лента и таблица всегда работают с полным `data/index.json`.

## Как поменять hero-баннер

1. Положите новую картинку в `assets/img/`.
2. Обновите `assets/img/hero-stage.webp` и `.jpg` (или поменяйте путь в
   `index.html`).
3. Пропорции влияют только на высоту блока: изображение стоит в потоке и не
   обрезается. Если картинка темнее/светлее, отрегулируйте контраст текста
   правилом `.lp-title { color: … }` в `theme.css`.

## Как обновить превью карты

Превью — обычный скриншот приложения:

1. откройте `map.html`, выберите нужный год;
2. спрячьте панели (шапка, кнопки, подсказка) или обрежьте кадр;
3. сохраните как `assets/img/map-preview.jpg` (и `.webp`) в пропорции 16 : 8.8.

## Дисклеймеры и звёздочки

Сноски стоят в футере лендинга (`index.html`) и приложения (`map.html`):

* `*` — все материалы проверены Автором, не являющимся профессиональным историком;
* `**` — не рекомендуется использовать для подготовки к ЕГЭ и научным публикациям.

Значки в блоке преимуществ ведут именно к этим сноскам (`<sup>*</sup>`, `<sup>**</sup>`).

## Локальный запуск и публикация

```bash
python3 -m http.server 8080      # из корня репозитория → http://localhost:8080/
```

Файлы открывать как `file://` нельзя: браузер блокирует ES-модули и `fetch`
(`data/index.json`). Публикация — как раньше, через GitHub Pages.
