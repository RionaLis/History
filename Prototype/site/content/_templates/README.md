# Шаблоны для заполнения

Здесь лежат заготовки. Рабочая папка — `content/articles/`; шаблоны сайт
не показывает, он читает только файлы `.md` из `articles/`.

## Как пользоваться

1. Скопируйте нужный шаблон в `content/articles/` и переименуйте по-человечески:
   `07-kazaki-zasechnaya-liniya.md`. Имя файла — для вас и для git;
   идентификатор живёт в шапке.
2. Заполните шапку. Блок `<!-- КАК ЗАПОЛНЯТЬ -->` удалите перед публикацией:
   иначе он попадёт в текст статьи.
3. Пишите текст обычным Markdown. Связи с другими статьями — `[[Название статьи]]`.

## Какой шаблон брать

| Шаблон | Когда | Что в превью |
|---|---|---|
| `article-entity.md` + `article-entity.wikidata.json` | Есть сущность в Wikidata: битва, человек, место, год | карточка фактов + ссылка на Википедию |
| `article-authorial.md` | Своего предмета в Wikidata нет: разбор источников, историография, «как ищут место» | своё вступление + оглавление |

Правило: **одна статья — одна сущность.** Если в тексте оказываются две,
это признак, что статью пора разделить.

## Обязательные поля шапки

| Поле | Смысл |
|---|---|
| `id` | Постоянный номер. У сущности — Q-номер Wikidata. У авторской статьи — свой, латиницей. **Не меняется никогда.** |
| `type` | `entity` или `authorial` — определяет вид превью |
| `title`, `summary`, `preview` | Заголовок, строка для карточки, бесплатное вступление |
| `topic` | Только из списка тем ниже |
| `body` | Уровень, с которого открыт полный текст (`0` — всем, `1` — подписка) |
| `extras` | Уровень для панели связей и доп. полей (по умолчанию `2`) |
| `updated` | Дата последней правки |
| `published_at` | Дата публикации; будущая — значит «ещё не показывать» |

Уровень доступа проставляется **при написании**, а не потом: выбрать его
задним числом для двухсот статей — отдельная неделя работы.

## Темы

Сейчас в базе: `Предыстория`, `Сражение`, `Люди`, `Источники`, `Последствия`,
`Реконструкция`. Новую тему добавляйте осознанно: сорок тем хуже, чем семь.

## Картинка в карточке сущности

Файл кладётся в `public/img/`, а в снимке `.wikidata.json` заполняется блок `image`:
путь, ширина и высота (чтобы страница не «прыгала» при загрузке), подпись, автор,
лицензия и ссылка на страницу файла.

Правила:

- для статей о сущностях берите файл из Викисклада — он уже свободный;
- **автора и лицензию указывать обязательно**, рядом со ссылкой на источник;
- в шапке карточки подпись вида «Иван Блинов · Public domain» — этого достаточно
  для изображений в общественном достоянии и для CC BY / CC BY-SA со ссылкой;
- не берите картинку из поиска без лицензии, даже для теста — потом забудется.

В настоящей версии всё это (адрес, подпись, автор, лицензия) приходит из Wikidata
вместе с файлом, скрипт скачивает картинку и кладёт её в `public/img/`.

## Видео

Запись о видео добавляется в `content/videos.json` по шаблону
`video-entry.json`. Поле `article` связывает видео со статьёй (по `id`),
`exclusive: true` — лекция закрытого доступа.

## Чек-лист перед публикацией статьи

- [ ] `id` не совпадает с другой статьёй и не менялся
- [ ] `type` правильный; у сущности заполнен `wikidata` и лежит снимок `.wikidata.json`
- [ ] `topic` из списка
- [ ] `preview` — свой текст, не пересказ Википедии (иначе страница-зеркало)
- [ ] текст Википедии не попал в платную часть
- [ ] `body` и `extras` проставлены
- [ ] все `[[ссылки]]` ведут на существующие статьи
- [ ] блок инструкций из шаблона удалён
