Площади, толщины и цвета

Подготовка временных рядов площадей для карточек государств. Импортируйте CSV с измерениями из OpenHistoricalMap, проверьте рассчитанные доли полос и выгрузите данные для MD.

1. Источник данных

Шаблон CSV: id,year,area_km2,lane. Используйте ID карточки из каталога; если государство охватывает несколько дорожек, внесите строку для каждой дорожки. Несколько лет создают меняющуюся толщину.

Формула: доля = max-доля × √(площадь / максимальную площадь набора). При наложении государств существующая раскладка таблицы нормирует сумму до высоты дорожки.

2. Единая цветовая палитра

Унификация на основе ID/региона: одинаковый объект получает одинаковый цвет в таблице и на карте. Карточки с цветом в YAML сохраняют его; кнопка ниже предлагает устойчивую цветовую палитру по группам.

Цветовая схема пока является редакторским предложением: экспортируйте цвета в MD после проверки, чтобы не перезаписывать вручную заданные палитры.

4. Выгрузка для MD

Площади сохраняются явно в area_series, а значения толщины — в совместимом с текущей таблицей spans (точки [год, доля]). Скопируйте фрагменты в карточки или используйте CSV как промежуточный журнал измерений.
