## Переписано
* `index.html` — теперь лендинг: hero-баннер (текст на той же «бумаге», что и
  коллаж), кнопки и преимущества под ним, 16 эпох из `data/index.json`,
  карточка «Интерактивная карта мира» с превью-скриншотом и переходом в приложение,
  полоса из 11 эпох с пиктограммами (Неолит → Новейшее время, даты из индекса),
  блок «События» (4 последних события из индекса), три карточки-ссылки,
  блок с цитатой, футер со сносками `*` и `**`.
* `map.html` — бывший `index.html`: вся разметка карта · лента · шкала · таблица
  без изменений логики; новая шапка «Хрониста», ссылки («Таблица» ведёт на
  `map.html#table`), футер со сносками. Подключены `fonts.css` и `theme.css`.
* `pages/*.html` — подключены шрифты и тема, `body.inner`, новые заголовки.
* `assets/js/pages.js` — новая шапка (бренд «Хрониста»), ссылки на `map.html`,
  `chartHref()` теперь ведёт на `map.html#…`.
* `content/articles/about.md` — первый абзац про «Хронисту».
* `README.md` — шапка с брендом и ссылкой на `README-DESIGN.md`.

## Не тронуто
`assets/js/app.js`, `chart.js`, `feed.js`, `map-app.js`, `scale.js`, `layout.js`,

## Как проверить локально
```bash
cd hronista-integration
python3 -m http.server 8080
# http://localhost:8080/      — лендинг
# http://localhost:8080/map.html — карта, лента и таблица
```

## Как влить в репозиторий
```bash
# из папки с вашим клоном репозитория History
cp -r путь/к/hronista-integration/. .
git add -A
git commit -m "Редизайн «Хрониста»: лендинг, тема, шапка, внутренние страницы"
git push
```

Проверено в браузере: лендинг, карта, лента, таблица, четыре внутренние
страницы — без ошибок в консоли; адаптив 1536 / 1280 / 1024 / 768 / 390 px.
