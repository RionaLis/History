# Империя Цин (маньчжуры)

> Маньчжурская империя — крупнейшее по территории государство Восточной Азии Нового времени.

| | |
|---|---|
| **Тип** | империя |
| **Период** | 1636 н.э. — 1912 н.э. |
| **Регионы** | Корея, Япония, Маньчжурия, Северный Китай, Южный Китай, Тибет и Монголия, Центральная Евразия |

## Подробнее

Цин удвоила территорию Китая за счёт Джунгарии, Синьцзяна, Тибета и Монголии. XIX век принёс Опиумные войны, Тайпинское восстание (20—30 млн погибших) и «неравноправные договоры», завершившиеся Синьхайской революцией 1911 года.
