# О проекте

**Хронолента мира** — интерактивная синхронологическая таблица всемирной истории:
по вертикали расположены регионы мира и их суб-регионы, по горизонтали — время
от 3000 г. до н.э. до 2000 г. н.э. На этом поле нанесены народы, культуры и
государства (цветные ленты), линии переселений (стрелки) и ключевые события
(пиктограммы).

## Как читать таблицу

| Элемент | Значение |
|---|---|
| Строка | макро-регион (например, «Европа») и его суб-регионы — дорожки |
| Лента | народ, культура или государство во времени |
| Толщина ленты | доля площади суб-региона, занятая этим государством; меняется во времени |
| Несколько лент одного цвета в разных строках | государство, охватившее несколько регионов |
| Пунктирная стрелка | переселение народа; сплошная красная — вторжение |
| Пиктограмма | ключевое событие: битва, восстание, технология, катастрофа и т. д. |

Наведение мыши даёт краткую справку, щелчок открывает подробную статью,
двойной щелчок вписывает объект в экран. Колесо мыши меняет масштаб времени
(от обзора всех 5000 лет до 100–200 лет на экране), перетаскивание сдвигает поле,
Shift + колесо прокручивает по вертикали.

## Где лежат данные

Весь контент — обычные markdown-файлы с YAML-фронтматтером, пригодные для
Obsidian:

```
content/
  regions/     — макро-регионы и состав их дорожек
  eras/        — эпохи (верхняя полоса таблицы)
  entities/    — народы, культуры, государства (по регионам)
  events/      — ключевые события
  migrations/  — линии переселений
  articles/    — свободные статьи и документация
data/index.json — собранный индекс, который читает сайт
```

Пример фронтматтера государства:

```yaml
---
id: rome_emp
name: Римская империя
kind: entity
type: empire          # state | empire | people | culture | polity | colony | confed
start: -27
end: 476
region: eu
color: "#c9a76a"
summary: Краткое описание в одну строку — оно всплывает по наведению.
spans: [{"lane": "eu_ita", "points": [[-27, 0.97], [400, 0.9], [476, 0.4]]},
        {"lane": "sw_egy", "points": [[-30, 0.9], [476, 0.8]]}]
---
```

`spans` — это и есть «география» объекта: для каждой дорожки задаётся ломаная
`[год, доля]`, где доля от 0 до 1 — какую часть суб-региона занимает государство.
Именно она превращается в толщину ленты, поэтому одна и та же держава может
быть широкой в своём ядре и узкой на периферии.

## Рабочий цикл

1. Откройте папку репозитория как хранилище Obsidian и правьте любые файлы в `content/`.
2. Выполните `python3 tools/build.py` — он проверит ссылки на дорожки и пересоберёт `data/index.json`.
3. Закоммитьте изменения: GitHub Pages отдаст обновлённый сайт.
   В репозитории настроено действие GitHub Actions, которое пересобирает индекс автоматически.

Для первичного наполнения использовался скрипт `tools/seed_content.py`
(он создаёт md-файлы из компактных таблиц в `tools/seed/`). Повторно его
запускать не нужно: без флага `--force` он не трогает существующие файлы.
